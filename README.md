# Python Arch Manager

Herramientas en **Python** para gestionar, auditar y automatizar tareas en **Arch Linux**.

## Características
- Auditoría de paquetes instalados
- Verificación de actualizaciones de seguridad
- Scripts de mantenimiento del sistema
- Integración con `pacman` y AUR

## Estructura
```
├── scripts/
├── modules/
├── config/
└── examples/
```

## Requisitos
```bash
pip install -r requirements.txt
```

## Uso
```bash
python -m arch_manager --audit
```

---
Hecho para usuarios de Arch que quieren más control y seguridad.
